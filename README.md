# Caballete

Galería en línea donde cada artista tiene su propio catálogo.

- App: PWA sin framework (`index.html`, `styles.css`, `app.js`), publicada con GitHub Pages.
- Datos, login y fotos: Supabase (proyecto `caballete`). Las reglas de seguridad (RLS) hacen que cada artista solo pueda tocar sus propias obras; el precio solo se expone si el artista elige mostrarlo.
- Las obras de prueba están en `img/seed/` (capturas de Instagram, usadas con fines de prototipo).
